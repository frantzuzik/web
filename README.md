# Cook Book

Статическая страница кулинарной книги — каталог из шести рецептов
и форма поиска. Только HTML, CSS и картинки, без JavaScript и сервера.

## Для кого

Для тех, кто хочет готовить дома и ищет идеи блюд по времени
и сложности.

## Блоки страницы

- `<header>` — название и навигация
- `<section class="hero">` — заголовок и описание
- `<section id="recipes">` — шесть карточек `<article>`
- `<section id="search">` — форма поиска
- `<footer>` — источники изображений

## Объект каталога

Рецепт: название, описание, время, сложность, кухня, изображение.

## Форма

| Поле | Тип | Атрибуты |
|---|---|---|
| Название или ингредиент | `input type="text"` | `id="query"`, `name="query"` |
| Время | `select` | `id="time"`, `name="time"` |
| Кнопка | `button type="submit"` | — |

`<label for>` связан с полем через `id`.

## Grid и Flexbox

**Grid** — сетка карточек: `repeat(auto-fit, minmax(260px, 1fr))`.
Контроль в двух измерениях.

**Flexbox** — одномерные раскладки: шапка, меню, форма, карточка.

## Адаптивность

| Ширина | Карточки |
|---|---|
| 360 px | 1 колонка |
| 768 px | 2 колонки |
| 1280 px | 3 колонки |

Горизонтальной прокрутки нет.

## Как открыть

Открыть `index.html` в браузере или запустить
`python -m http.server 8000` и перейти на http://localhost:8000.
