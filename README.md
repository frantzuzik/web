# Cook Book

Статическая страница кулинарной книги — первая версия учебного веб-приложения.
Содержит каталог рецептов и форму поиска.

## Для кого

Для людей, которые хотят готовить дома и ищут идеи блюд по времени
приготовления и сложности.

## Основные блоки страницы

- Шапка с названием проекта и навигацией
- Главный заголовок и краткое описание
- Каталог из шести карточек рецептов
- Форма поиска и фильтрации
- Подвал с источниками изображений

## Как открыть

1. Скачать репозиторий (Code → Download ZIP) и распаковать.
2. Открыть файл `index.html` в браузере.

Или запустить локальный сервер из папки проекта:

```bash
python -m http.server 8000
