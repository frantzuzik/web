# Cook Book

Интерактивное веб-приложение — каталог рецептов на чистом JavaScript
(Vanilla JS). SPA с поиском, фильтрацией, сортировкой, добавлением
и удалением элементов. Данные сохраняются в localStorage.

## Для кого

Для тех, кто хочет готовить дома и ищет идеи блюд по времени,
сложности и кухне.

## Функционал

- **Поиск** в реальном времени по названию и описанию (`input`)
- **Фильтр** по кухне (`select` с пунктом «Все кухни»)
- **Сортировка**: название А–Я / Я–А, время по возрастанию / убыванию
- **Модальное окно** добавления рецепта (закрытие: крестик, «Отмена»,
  клик по подложке, Escape)
- **Валидация формы** через Constraint Validation API
  (`required`, `minlength`, `maxlength`, `min`, `max`, `type="url"`)
- **Удаление** карточек через делегирование событий
- **localStorage** — данные сохраняются между перезагрузками

## Объект каталога

Рецепт: `id`, `title`, `description`, `time`, `difficulty`, `cuisine`, `image`.

Начальные данные — шесть рецептов (карбонара, том ям, шакшука,
панкейки, борщ, тирамису).

## Блоки страницы

- `<header>` — название и навигация
- `<section class="hero">` — заголовок и описание
- `<section id="search">` — панель управления (поиск, фильтр, сортировка, кнопка «Добавить»)
- `<section id="recipes">` — сетка карточек
- `<footer>` — источники изображений
- `<div class="modal">` — модальное окно добавления

## Архитектура: State-Driven UI

Всё состояние приложения в одном объекте:

```js
const state = {
    items: [],               // массив рецептов
    searchQuery: '',         // строка поиска
    selectedCategory: 'all', // выбранная кухня
    sortBy: 'name-asc'       // режим сортировки
};
```

Интерфейс — функция от состояния: `UI = render(state)`. Любое действие
пользователя меняет `state`, после чего вызывается `render()`.

## Grid и Flexbox

**Grid** — сетка карточек: `repeat(auto-fit, minmax(260px, 1fr))`.
Контроль в двух измерениях.

**Flexbox** — одномерные раскладки: шапка, панель управления,
форма в модалке, карточка.

## Безопасность и качество кода

- Только `const` и `let`, без `var`.
- Только строгое сравнение `===`.
- Для пользовательского ввода — `textContent`, не `innerHTML` (защита от XSS).
- Иммутабельная сортировка: `[...filtered].sort(...)` — исходный массив не мутируется.
- Без сторонних библиотек — Vanilla JS.

## Как открыть

Через локальный сервер (обязательно — при `file://` localStorage
блокируется браузером):

```bash
python -m http.server 8000
```

Открыть http://localhost:8000.

## Как пользоваться

1. Введите запрос в поле поиска — карточки фильтруются в реальном времени.
2. Выберите кухню в фильтре — остаются только рецепты этой кухни.
3. Поменяйте сортировку — карточки переставляются.
4. Нажмите «Добавить рецепт» — откроется модальное окно. Заполните
   форму; при ошибках появятся подсказки под полями.
5. Нажмите «Удалить» на карточке, чтобы убрать рецепт.
6. Обновите страницу — все изменения сохранились в localStorage.

## Проверки

- HTML-валидатор (validator.w3.org) — без ошибок.
- DevTools → Network — HTML, CSS, JS и изображения отдельными
  запросами со статусом 200.
- DevTools → Application → Local Storage — ключ `cookbook.items.v1`.
- Проверены ширины 360, 768, 1280 px.
- Все интерактивные элементы доступны с клавиатуры, рамка фокуса видна.
