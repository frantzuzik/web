# РецептБокс

Веб-приложение для поиска рецептов по времени приготовления и сложности.

## Для кого

Для людей, которые хотят готовить дома и ищут идеи блюд.

## Основные блоки страницы

- Шапка с навигацией
- Главный заголовок и описание
- Каталог из 6 рецептов (карточки)
- Форма поиска
- Блок «О проекте»
- Подвал

## Как открыть

Скачай репозиторий и открой `index.html` в браузере.
