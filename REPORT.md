## 1. Введение

### 1.1. Цель работы

Разработать статическую клиентскую часть будущего веб-приложения: создать главную страницу с коллекцией однотипных объектов, формой поиска и информационными блоками, оформить её с помощью CSS и обеспечить адаптивность под мобильные, планшетные и десктопные экраны.

### 1.2. Задачи

1. Выбрать тему проекта и определить объект коллекции.
2. Свёрстать страницу с семантической разметкой HTML.
3. Оформить её в отдельном CSS-файле.
4. Применить CSS Grid и Flexbox по назначению.
5. Обеспечить адаптивность на ширинах 360, 768 и 1280 пикселей.
6. Проверить доступность с клавиатуры и валидность HTML.
7. Организовать структуру проекта и заполнить README.

### 1.3. Выбранная тема

Cook Book — каталог рецептов. Объект коллекции — рецепт. Свойства объекта: название, описание, время приготовления, сложность, кухня, изображение.

Тема выбрана потому, что каталог рецептов легко расширяется на следующих этапах курса: фильтрация по ингредиентам, сохранение в избранное, добавление своих рецептов и личный кабинет.

## 3. Структура страницы

Страница построена на семантических тегах HTML5. Основные блоки следующие.

Шапка. Тег header. Содержит название проекта и навигацию.

Навигация. Тег nav со списком ul и ссылками a. Ссылки ведут по якорям к разделам страницы.

Главный блок. Тег section с классом hero. Содержит заголовок первого уровня и краткое описание проекта.

Каталог рецептов. Тег section с идентификатором recipes. Содержит шесть карточек рецептов.

Карточка рецепта. Тег article с классом card. Это самостоятельный объект каталога.

Форма поиска. Тег section с идентификатором search, внутри — тег form.

Подвал. Тег footer. Содержит источники изображений.

### 3.1. Иерархия заголовков

На странице один заголовок первого уровня h1 — в блоке hero, текст «Рецепты на каждый день». Заголовки второго уровня h2 — у секций: «Каталог рецептов» и «Найти рецепт». Заголовки третьего уровня h3 — у каждой карточки: «Паста карбонара», «Том Ям» и так далее.

Уровни не пропускаются, заголовок первого уровня только один. Если убрать CSS и изображения, по одним заголовкам структура страницы остаётся понятной.

### 3.2. Служебная часть документа

В блоке head указаны:

декларация doctype html, которая сообщает браузеру, что это HTML5;

атрибут lang="ru" у тега html, который указывает язык страницы;

метатег charset="UTF-8" для корректного отображения кириллицы;

метатег viewport, чтобы мобильные браузеры открывали страницу по ширине экрана;

тег title с осмысленным названием вкладки;

тег link, подключающий файл стилей.


## 4. Карточки рецептов

На странице шесть рецептов с осмысленными данными.

Паста карбонара. Время: 25 минут. Сложность: средняя. Кухня: итальянская.

Том Ям. Время: 40 минут. Сложность: сложная. Кухня: тайская.

Шакшука. Время: 20 минут. Сложность: лёгкая. Кухня: ближневосточная.

Панкейки. Время: 15 минут. Сложность: лёгкая. Кухня: американская.

Борщ. Время: 90 минут. Сложность: средняя. Кухня: восточноевропейская.

Тирамису. Время: 30 минут. Сложность: средняя. Кухня: итальянская.

Карточки отличаются не только названием, но и всеми свойствами. По странице видно, что представляет собой каталог.

### 4.1. Разметка одной карточки

Карточка — это тег article с классом card. Внутри него тег img с изображением блюда и атрибутом alt, затем div с классом card__body, в котором лежат заголовок третьего уровня h3, абзац с описанием и список ul с классом card-props, содержащий два свойства: время и сложность.

Тег article выбран потому, что каждый рецепт это самостоятельный объект: если вырвать карточку из страницы, она останется осмысленной. Тег h3 — третий уровень, потому что h1 уже занят в hero, а h2 — у секции. Тег img с атрибутом alt даёт текстовую альтернативу для скринридеров и на случай, если файл не загрузится. Блок card__body — это div, потому что семантической роли у него нет, он нужен только для технической группировки текста под картинкой.


## 5. Форма поиска

Форма содержит поля разных типов и кнопку отправки.

Первое поле — текстовое. Тип input="text", идентификатор id="query", имя name="query". Подпись — «Название или ингредиент».

Второе поле — выпадающий список select с идентификатором id="time" и именем name="time". Подпись — «Время приготовления». Внутри четыре опции: любое, до 20 минут, от 20 до 40 минут, больше 40 минут.

Кнопка отправки — тег button с типом type="submit" и текстом «Найти».

### 5.1. Пояснения

Тег label с атрибутом for="query" связан с полем input id="query" через атрибуты for и id. Это даёт три вещи: клик по подписи ставит курсор в поле, скринридер озвучивает подпись при обходе, область клика увеличивается для мобильных.

Атрибут name у полей понадобится при отправке данных на сервер на следующих этапах. Сервер получит значения вида query=паста и time=20.

Тег button type="submit" — это настоящая кнопка отправки, а не div со стилями. Она работает с клавиатуры и озвучивается скринридером как кнопка.

Форма пока не выполняет поиск. Интерактивность добавится в следующей лабораторной работе.


## 6. CSS: Grid и Flexbox

### 6.1. CSS Grid — сетка карточек

Для сетки карточек используется свойство display: grid. Колонки заданы через repeat(auto-fit, minmax(260px, 1fr)), отступы — через gap.

Grid выбран потому, что здесь нужен контроль в двух измерениях: и по колонкам, и по рядам. Связка auto-fit и minmax(260px, 1fr) даёт адаптивную сетку без медиазапросов. На ширине 360 пикселей получается одна колонка, на 768 — две, на 1280 — три. Браузер сам считает, сколько колонок минимум по 260 пикселей поместится в контейнер, и растягивает их на равные доли. Свойство gap задаёт отступы и по горизонтали, и по вертикали одним правилом.

Grid используется только для класса cards. Остальные раскладки одномерные, там уместен Flexbox.

### 6.2. Flexbox — где применяется

Flexbox используется в следующих местах.

Класс header__inner — логотип слева, меню справа, выравнивание через justify-content: space-between.

Класс nav-list — пункты меню в ряд.

Класс search-form — поля формы в ряд с переносом через flex-wrap.

Класс field — подпись сверху, поле снизу, направление колонкой.

Класс card — картинка сверху, тело снизу, направление колонкой.

Класс card__body — заголовок, описание и свойства рецепта, направление колонкой.

Класс card-props — свойства «25 мин» и «Средняя» в ряд.

Flexbox выбран потому, что задачи одномерные: расположить элементы вдоль одной оси и распределить между ними пространство.

### 6.3. Разница подходов

Grid — двумерная сетка, контроль и по строкам, и по столбцам. Flexbox — одномерная раскладка вдоль одной оси, с переносом при необходимости. Эти технологии не заменяют друг друга, а дополняют. Сетка карточек — Grid, внутренности шапки, формы и карточки — Flexbox.

### 6.4. Переменные

В псевдоклассе root объявлены CSS-переменные: цвет фона, цвет поверхности, основной цвет текста, приглушённый цвет текста, цвет линий, акцентный цвет, радиус скругления, отступ и максимальная ширина контейнера. Все цвета и отступы берутся из этих переменных, поэтому для изменения акцентного цвета достаточно отредактировать одну строку.

### 6.5. Сброс стилей

В селекторе со звёздочкой заданы box-sizing: border-box, margin: 0 и padding: 0. Свойство box-sizing: border-box критично для сеток. Без него padding и border добавляются к ширине элемента, и карточка с минимальной шириной 260 пикселей становится шире, ломая раскладку.


## 7. Адаптивность

Страница проверена при трёх ширинах.

При 360 пикселях карточки в одну колонку, шапка с логотипом и меню по центру, поля формы в столбик.

При 768 пикселях карточки в две колонки, шапка в одну строку, поля формы в строку.

При 1280 пикселях карточки в три колонки, шапка в одну строку, поля формы в строку.

### 7.1. Как это достигается

Сетка карточек перестраивается сама за счёт repeat(auto-fit, minmax(260px, 1fr)) — без медиазапросов. Форма и шапка перестраиваются на узких экранах через медиазапрос с условием max-width: 600 пикселей. В нём шапка центрируется, форма переключается на направление колонкой, кнопка растягивается на всю ширину.

Горизонтальная прокрутка не появляется ни на одной ширине. Изображения не выходят за пределы карточек за счёт свойства object-fit: cover и фиксированной высоты.


## 8. Доступность

Все интерактивные элементы доступны с клавиатуры. Порядок обхода по клавише Tab совпадает с визуальным.

У ссылок, кнопок и полей есть видимая рамка фокуса, оформленная через псевдокласс focus-visible в акцентном цвете. Этот псевдокласс показывает рамку только при навигации с клавиатуры, не при клике мышью. Методичка требует не убирать рамку, поэтому она оформлена своим стилем.

У всех изображений есть осмысленный атрибут alt, описывающий блюдо.

Разметка семантичная: используются теги header, nav, main, section, article, footer.

Подписи формы связаны с полями через атрибуты for и id.


## 9. Проверки

HTML проверен валидатором W3C по адресу validator.w3.org. Ошибок и предупреждений нет.

CSS проверен валидатором по адресу jigsaw.w3.org/css-validator. Ошибок нет.

В панели разработчика на вкладке Network видно, что браузер получает HTML, CSS и каждое из шести изображений отдельными запросами. Все запросы со статусом 200.

Проверены ширины 360, 768 и 1280 пикселей. Горизонтальной прокрутки нет, текст читается, изображения находятся внутри карточек.

Проверен обход по клавише Tab: рамка фокуса видна на всех интерактивных элементах.
