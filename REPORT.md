## 1. Тема и объект

**Тема проекта:** каталог рецептов.
**Объект коллекции:** рецепт.
**Свойства объекта:** название, описание, время приготовления,
сложность, кухня, изображение.

Тема выбрана потому, что каталог рецептов легко расширяется
на следующих этапах: фильтрация по ингредиентам, сохранение
в избранное, добавление своих рецептов и личный кабинет.

## 2. Структура страницы

| Блок | HTML-элемент | Назначение |
|---|---|---|
| Шапка | `<header>` | Название проекта и навигация |
| Навигация | `<nav>`, `<ul>` | Переходы к разделам страницы |
| Главный блок | `<section class="hero">` | Заголовок и описание проекта |
| Каталог | `<section id="recipes">` | Шесть карточек рецептов |
| Карточка | `<article>` | Самостоятельный объект каталога |
| Форма поиска | `<section id="search">`, `<form>` | Поиск и фильтрация |
| Подвал | `<footer>` | Источники изображений |

Заголовки выстроены иерархично: один `<h1>` на странице,
`<h2>` для разделов, `<h3>` для названий карточек.
По одним заголовкам понятна структура страницы, даже если
убрать CSS и изображения.

## 4. Форма поиска

Форма содержит поля разных типов и кнопку отправки:

| Поле | Тип | Атрибуты |
|---|---|---|
| Название или ингредиент | `input type="text"` | `id="query"`, `name="query"` |
| Время приготовления | `select` | `id="time"`, `name="time"` |
| Кнопка отправки | `button type="submit"` | — |

У каждого поля есть видимая подпись `<label for="...">`,
связанная с полем через `id`. Атрибуты `name` пригодятся
при отправке данных на сервер на следующих этапах.

Форма пока не выполняет поиск — интерактивность добавится
в следующей лабораторной работе.

## 5. Изображения

У каждой карточки есть изображение блюда с осмысленным `alt`,
описывающим рецепт. Изображения лежат в `assets/images/`
и подключены относительными путями. Источники указаны в README
и в подвале страницы.
